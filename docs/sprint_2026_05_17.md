## Context

This repository is one of two portfolio projects targeted by the 2026-05 weekend sprint. The goal of this single-day sprint is to bring the project up to modern Analytics Engineering standards by adding:

- A **second warehouse target (Snowflake)** alongside the existing BigQuery setup — same dbt project runs on both adapters
- **GitHub Actions CI** that runs `dbt build` + `sqlfluff lint` on every PR
- **SQLFluff + pre-commit** for code-quality enforcement
- **dbt docs** deployed publicly to GitHub Pages
- **README rewritten** as a defensible case study (Problem / Approach / Tradeoffs / Migration Experience)

What stays unchanged:
- Existing 8 dbt models (4 staging + 4 marts) and 20 dbt tests
- Synthetic data generation script (`data/generate_data.py`) — 4 CSVs, ~220K rows total
- Airflow DAG (`airflow/dags/feature_analytics_dag.py`) and Docker Compose

Companion project (e-commerce-analytics) covers the PySpark / Microsoft Fabric / Power BI / Medallion / Star Schema / Azure keywords. This project covers dbt / Snowflake / BigQuery / GitHub Actions / SQLFluff / dbt docs / Looker / Airflow / Docker / GCP / pre-commit.

3. In Worksheets, run as SYSADMIN:

```sql
CREATE OR REPLACE WAREHOUSE TRANSFORMING_WH
  WITH WAREHOUSE_SIZE = 'XSMALL'
  AUTO_SUSPEND = 60
  AUTO_RESUME = TRUE
  INITIALLY_SUSPENDED = TRUE;

CREATE OR REPLACE DATABASE ANALYTICS;
CREATE SCHEMA ANALYTICS.RAW;
CREATE SCHEMA ANALYTICS.STAGING;
CREATE SCHEMA ANALYTICS.MARTS;
CREATE SCHEMA ANALYTICS.CI;

CREATE OR REPLACE ROLE TRANSFORMER;
GRANT USAGE ON WAREHOUSE TRANSFORMING_WH TO ROLE TRANSFORMER;
GRANT ALL ON DATABASE ANALYTICS TO ROLE TRANSFORMER;
GRANT ALL ON ALL SCHEMAS IN DATABASE ANALYTICS TO ROLE TRANSFORMER;
GRANT ALL ON FUTURE SCHEMAS IN DATABASE ANALYTICS TO ROLE TRANSFORMER;
GRANT ALL ON FUTURE TABLES IN DATABASE ANALYTICS TO ROLE TRANSFORMER;

CREATE OR REPLACE USER DBT_USER
  PASSWORD = '<save this>'
  DEFAULT_ROLE = TRANSFORMER
  DEFAULT_WAREHOUSE = TRANSFORMING_WH;
GRANT ROLE TRANSFORMER TO USER DBT_USER;
```

4. Smoke test: `SELECT CURRENT_USER(), CURRENT_ROLE(), CURRENT_WAREHOUSE();`

### A4 (11:00-12:30) — dbt Build on Snowflake + Fix Incompatibilities

1. `dbt deps`
2. `dbt build --target snowflake_prod`
3. Expected BQ → SF incompatibility points:
   - `DATE_DIFF(a, b, DAY)` → `DATEDIFF('day', b, a)` (argument order flips)
   - `SAFE_CAST` → `TRY_CAST`
   - `STRUCT/ARRAY` → `OBJECT/ARRAY`
   - Backtick identifiers → double-quote identifiers
   - `IFNULL` → `COALESCE` (standardize)
4. Fix strategy: prefer rewriting to ANSI-SQL so both targets pass; fall back to `{% if target.type == 'snowflake' %}` only when unavoidable.
5. Log each fix to `docs/migration_notes.md`. Example:
   ```markdown
   - `models/marts/fct_cohort_retention.sql`: `DATE_DIFF(end, start, DAY)` → `DATEDIFF('day', start, end)`. BigQuery and Snowflake reverse the argument order.
   ```
6. Goal: `dbt build --target snowflake_prod` all green (8 models + 20 tests).

### A6 (14:30-16:00) — GitHub Actions CI + SQLFluff + pre-commit

1. `.sqlfluff`:
```ini
[sqlfluff]
dialect = snowflake
templater = dbt
exclude_rules = L034
max_line_length = 120

[sqlfluff:templater:dbt]
project_dir = .
profiles_dir = .

[sqlfluff:rules:capitalisation.keywords]
capitalisation_policy = upper
```

2. `.sqlfluffignore`: `target/`, `dbt_packages/`, `logs/`

3. `.pre-commit-config.yaml`:
```yaml
repos:
  - repo: https://github.com/pre-commit/pre-commit-hooks
    rev: v4.5.0
    hooks:
      - id: trailing-whitespace
      - id: end-of-file-fixer
      - id: check-yaml
  - repo: https://github.com/sqlfluff/sqlfluff
    rev: 3.0.0
    hooks:
      - id: sqlfluff-fix
        files: ^models/.*\.sql$
        additional_dependencies: ['dbt-snowflake', 'sqlfluff-templater-dbt']
```

4. Run `sqlfluff fix models/`, commit once as `chore: apply sqlfluff formatting`.

5. `.github/workflows/dbt_ci.yml`:
```yaml
name: dbt CI
on: [pull_request]
jobs:
  dbt-ci:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.11'
      - run: pip install dbt-snowflake==1.7.* sqlfluff==3.0.* sqlfluff-templater-dbt
      - run: dbt deps
      - run: sqlfluff lint models/
      - name: dbt build
        env:
          SNOWFLAKE_ACCOUNT: ${{ secrets.SNOWFLAKE_ACCOUNT }}
          SNOWFLAKE_USER: ${{ secrets.SNOWFLAKE_USER }}
          SNOWFLAKE_PASSWORD: ${{ secrets.SNOWFLAKE_PASSWORD }}
          DBT_PROFILES_DIR: .
        run: dbt build --target snowflake_prod --vars '{"target_schema": "CI"}'
```

6. GitHub repo Settings → Secrets: add `SNOWFLAKE_ACCOUNT`, `SNOWFLAKE_USER`, `SNOWFLAKE_PASSWORD`.

7. Branch `ci/setup` → trivial change → push → open PR → verify CI green.
